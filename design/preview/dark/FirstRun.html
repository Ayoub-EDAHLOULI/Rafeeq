Add a model to get started

Rafeeq runs language models from files on this device. It does not include one and never downloads one for you, so nothing ever leaves this machine.

1
Download a GGUF file
On a computer with internet, search Hugging Face for a model with GGUF in the name. A file ending in Q4_K_M is a good balance of size and quality.
2
Copy it to this computer
Use a USB drive or an internal file share, then put the file in the models folder shown below.
3
Refresh
Rafeeq finds the file and lists it under Models. Nothing is uploaded or checked online.
